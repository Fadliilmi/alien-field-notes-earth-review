An alien tourist's one-line review of planet Earth: a visitor from the stars
admires our gorgeous blue planet and its friendly locals, then cannot believe
they spend whole afternoons chasing a tiny white ball with a metal stick, lose
it in the grass, and do it all again tomorrow — and still call it fun. `main.ts`
writes the single review line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
